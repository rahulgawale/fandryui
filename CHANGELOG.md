## [0.2.0](https://github.com/rahulgawale/fandryui/compare/v0.1.0...v0.2.0) (2026-09-06)

### Features

- add Jest test infrastructure (`@lwc/jest-preset`) and the `fd-select` primitive, with grouped-option (`<optgroup>`) support ([#23](https://github.com/rahulgawale/fandryui/pull/23))
- **badge,card:** add `fd-badge` (default/primary/success/warning/danger variants) and `fd-card` primitives ([#25](https://github.com/rahulgawale/fandryui/pull/25))
- **alert:** add `fd-alert` primitive with info/success/warning/danger variants ([#26](https://github.com/rahulgawale/fandryui/pull/26))
- **spinner:** add `fd-spinner` primitive with sm/md/lg sizes ([#28](https://github.com/rahulgawale/fandryui/pull/28))
- **divider:** add `fd-divider` primitive with horizontal/vertical orientation ([#29](https://github.com/rahulgawale/fandryui/pull/29))
- add `fd-skeleton` (text/circle/rect loading placeholder) and `fd-avatar` (image with initials fallback) primitives, `sm`/`md`/`lg` size variants for `fd-button` and `fd-input`, and a repo-wide design-token audit replacing hard-coded CSS values across every primitive ([#31](https://github.com/rahulgawale/fandryui/pull/31))

### Bug Fixes

- fix broken `npm run typecheck` (missing `typescript` devDependency) and inconsistent focus-ring styling between `fd-input` and native demo inputs ([#21](https://github.com/rahulgawale/fandryui/pull/21))
- **alert:** replace hard-coded CSS values with design tokens ([#27](https://github.com/rahulgawale/fandryui/pull/27))
