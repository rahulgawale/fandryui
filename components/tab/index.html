Parts

Link to section Parts

Style the elements inside the component from your own CSS with ::part(). Every fandry component renders in native shadow DOM, so parts work on LWR and Salesforce alike. For colors, spacing, radius and type across many components, set the --fd-* tokens instead. The code for the "Custom colors and parts" example above:

PartDescription
baseThe outermost element.

States are extra names on a part while the state is on. Name both to style one state, e.g.fandry-checkbox::part(control checked).

StateDescription
selectedThe chosen option, a selected table row, or the selected tab.
disabledA control, option or item that cannot be used.
<!-- template -->
<div class="brand">
  <fandry-tabs value="account" aria-label="Settings">
    <fandry-tab slot="tab" value="account">Account</fandry-tab>
    <fandry-tab slot="tab" value="billing">Billing</fandry-tab>
    <fandry-tab slot="tab" value="team">Team</fandry-tab>
    <fandry-tab-panel value="account">
      <fandry-text>Update your name, email and password.</fandry-text>
    </fandry-tab-panel>
    <fandry-tab-panel value="billing">
      <fandry-text>Manage your plan and payment method.</fandry-text>
    </fandry-tab-panel>
    <fandry-tab-panel value="team">
      <fandry-text>Invite people to your workspace.</fandry-text>
    </fandry-tab-panel>
  </fandry-tabs>
</div>

/* css */
/* Scoped to this demo. Set the same --fd-* tokens on :root to theme
   every fandry-* component on the site. */
.brand {
  --fd-primary: 160 84% 26%;
}

fandry-tabs::part(list) {
  gap: 0.5rem;
  box-shadow: none;
}

fandry-tab::part(base) {
  border-radius: 999px;
  border-bottom-color: transparent;
}

fandry-tab::part(base selected) {
  background: hsl(160 84% 26%);
  color: white;
}
